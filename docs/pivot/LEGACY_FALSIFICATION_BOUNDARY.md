# Legacy falsification boundary

Falsification/HIG modules remain intact for reproducibility, but are `LEGACY_RESEARCH_TRACK` and `NOT_DEFAULT_BATTERY_PROCESS_PATH`.

The default process package has no imports from `src.science.falsification`, hypothesis models/backends, HIG estimators, or `src.science.multimodal`. Its action is a complete recipe or next-stage control proposal, never `candidate × measurement modality`.

No UI migration is included in this pivot. Existing falsification screens remain historical artifacts until a separately verified process benchmark exists.

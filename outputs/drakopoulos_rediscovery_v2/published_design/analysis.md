# Published Alchemite Design Validation Analysis

The Alchemite-optimized electrode published in Drakopoulos et al. (2021) Cell Reports Physical Science represents an aggregated formulation/process comparison rather than an individually labeled Mendeley run in the open repository deposit (10.17632/4dh2h3tsf4.1). In the open dataset, only Partition A (AS series) and Partition B (ASC prospective series) are present with cell cycling records. Table S5 provides target specifications (D30 > 150 mAh/g, active mass > 25 mg), but independent validation data for that specific cell is not released as an open cell cycling file.
